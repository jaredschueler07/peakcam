## 3. Lessons worth keeping

**Sandboxed agents cannot see rendering bugs — and neither can unit tests.**
Phase 11 took five browser rounds. Every round the suite was green while the frame was
wrong: LUT grading in the wrong colour space; WGSL `sin()` returning NaN at Heavenly's
3 km coordinates; CSM subtracting light into negative values, producing black terrain;
WebGPU rendering point-sprites as single pixels. None were reachable without a real GPU.

**Measure, don't reason, about external data.** Heavenly's DEM killed three successive
theories — mine included — before `gdalinfo`/`gdallocationinfo` settled it. A staged tile
*existing* is not coverage: 3DEP acquisition boundaries end mid-tile, so tiles read as
nodata outside their collection area. Related: 3DEP filenames index the tile's **north**
edge, so the obvious `floor(northing/10000)` picks the tile below the one you want.

**Silence is the enemy.** Two of this session's worst bugs were silent: email that
reported success while being rejected, and a far-field asset 404 that degraded so
gracefully a browser round would have read as "no change, working as intended."
Both were found by checking the thing rather than the absence of complaints.

**Reviews caught what authors could not.** A redirect guard prescribed in our own security
review turned out to be bypassable (browsers strip tab/LF/CR *anywhere* in a URL). The
first ticket-recording fix introduced a worse regression than the bug. A `Permissions-Policy`
header would have silently killed the map's "find me" button. All caught before merge, all
by a second model reading the same diff.

**Duplication is where correctness goes to die.** Chasing a fog bug turned up **four**
hand-written copies of one curve with only two pinned together. The same pattern appeared
in fake test backends modelling renderers that do not exist — which is exactly how a
WebGPU-only `dispose()` crash reached a user.
