## 3. Lessons worth keeping

- **The screenshot gate catches what nothing else can** — but only if the
  frames are actually looked at, at the failing view. Round 1's "after" frame
  was 9 s into the run; the failing view was at 750 ms.
- **One-sided luminance guards cannot see a black sky** (it moves both
  metrics in the "passing" direction). Guards that measure live weather
  aren't guards; pin the inputs.
- **Debug flags beat theories**: `?nopost`/`?snowdbg` partitioned three bugs
  in minutes and contradicted every prior hypothesis (textures were innocent;
  two "different" bugs were one blend-arithmetic error).
- **Branch hygiene**: a PR cut from the wrong base nearly launched the game
  as a side effect of an email fix. Check `git diff main...HEAD --stat`
  before merging anything.
- **PGRST002 after disk-full**: dashboard says healthy, REST says 503 —
  terminate the authenticator backends before reaching for a full restart.
- **Playwright count wobble is a symptom, not noise** — chasing 20-vs-21
  found a real intermittent failure (Vercel analytics MIME-refusals
  attributing to the document, evading a URL-based filter).
