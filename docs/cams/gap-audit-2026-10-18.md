## 1. Method (reusable for P1 coverage imports)

1. Per resort, open the operator's webcam page (`cam_page_url` in `data/resorts.csv`; a third of them 404 or moved, corrections in section 5). Fetch the raw HTML with a browser User-Agent; Vail (Akamai), Alterra (Incapsula) and Cloudflare-fronted sites return a stub to curl and need a rendered fetch (Firecrawl) or browser-grade headers.
2. Find the cam list where the page keeps it: inline `<iframe>`/`<img>`, a JSON endpoint (`/api/weather/webcam`, Gatsby `page-data.json`, Next.js RSC payload, Nuxt client fetch), or `data-src` behind a consent gate. Read the embed each cam actually uses.
3. Normalise the embed: `camstreamer.com/embed/<token>` is a 302 to a YouTube embed, record the YouTube id; HD Relay `<div data-id>` is a *player* id, resolve `manage.hdrelay.com/player/<id>` to the camera id and use `img.hdrelay.com/camera/<id>/snapshot` (GET, HEAD returns 500); Brownrice `live7.brownrice.com/?sn=` script embeds map to `player.brownrice.com/embed/<sn>`; prism cams use `storage.googleapis.com/prism-cam-<id>/720.jpg`.
4. Verify: YouTube `oembed` 200; images GET 200 `image/*` with no Referer (hot-link check) and no cache-buster in the stored URL; iframes 200 with no `X-Frame-Options: DENY|SAMEORIGIN` and no `frame-ancestors` that excludes other sites. Skip anything offline, "coming soon", or only on the competitor's list.
5. Read the operator's terms if linked. Skip when framing, in-line linking or hot-linking is prohibited in so many words (Jackson Hole, Bridger Bowl, Boyne's Loon T&C); add and flag when the clause is a generic no-reproduction or anti-scraping line (Alterra, Vail), consistent with the 50-plus Vail and Alterra relays PeakCam already carries. Record the terms URL in `source_terms_url`.
6. Dedupe on `resort_slug` + `embed_url` and on `resort_slug` + YouTube id against the CSV (the importer upserts on `resort_id,embed_url,name`; prod `cams` has no other unique constraint).
